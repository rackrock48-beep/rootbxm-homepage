# 검색엔진 등록 (구글 + 네이버)

## 0. 준비
- 사이트가 배포되어 있어야 한다. 안 되어 있으면 `/deploy`를 먼저 실행한다.
- 사이트 주소는 `gh api repos/{owner}/{repo}/pages --jq .html_url`로 얻는다. 아래에서 `<주소>`라고 쓴다(끝에 `/` 포함).
- 브라우저 작업은 **Claude in Chrome**으로 한다. 사용자가 평소 쓰는 Chrome 또는 Edge를 그대로 쓰므로, 이미 로그인된 구글·네이버 계정을 쓸 수 있다.
- 연결이 안 되어 있으면(브라우저 도구가 없거나 `/chrome` 상태가 꺼져 있으면) 한 단계씩 안내한다.
  1. Chrome 웹 스토어에서 "Claude in Chrome" 확장 프로그램을 설치한다(Edge도 같은 스토어에서 설치 가능).
  2. 확장 프로그램 아이콘을 눌러 Claude 계정으로 로그인한다.
  3. Claude에서 `/chrome`을 입력하고 "Enabled by default"를 고른다.

## 로그인 원칙
- 비밀번호, 인증 코드는 **절대 묻지도 입력하지도 않는다.** 로그인 화면이나 보안 문자가 나오면 "브라우저에서 직접 로그인해 주세요. 끝나면 '했어'라고 말해 주세요."라고 안내하고 기다린다.

## 1. 구글 서치 콘솔
1. https://search.google.com/search-console 를 연다. 로그인이 필요하면 위 원칙대로.
2. 속성 추가에서 **URL 접두어** 방식을 고르고 `<주소>`를 입력한다. (도메인 방식은 DNS 설정이 필요해서 github.io 주소에는 쓸 수 없다.)
3. 소유권 확인 방법 중 **HTML 태그**를 고르고, `content="..."` 안의 값만 복사해 `src/site.ts`의 `verification.google`에 넣는다.
4. `/deploy`로 배포하고 끝날 때까지 기다린 뒤, 브라우저로 돌아와 **확인**을 누른다.
5. 왼쪽 메뉴 **Sitemaps**에서 `sitemap-index.xml`을 제출한다(입력칸 앞부분은 이미 `<주소>`로 채워져 있다).

## 2. 네이버 서치어드바이저
1. https://searchadvisor.naver.com/console/board 를 연다. 로그인이 필요하면 위 원칙대로.
2. 사이트 등록에 `<주소>`를 입력한다.
3. 소유 확인 방법 중 **HTML 태그**를 고르고, `content="..."` 안의 값만 `src/site.ts`의 `verification.naver`에 넣는다.
4. `/deploy`로 배포하고 끝나면 **소유확인**을 누른다.
5. 등록한 사이트로 들어가 **요청 > 사이트맵 제출**에 `<주소>sitemap-index.xml`을 넣는다. 오류가 나면 `<주소>sitemap-0.xml`로 다시 제출한다.
6. **검증 > robots.txt**에서 수집 허용 상태를 확인한다.

구글과 네이버를 함께 하면 3·4단계를 묶어 두 코드를 한 번에 넣고 한 번만 배포한다.

## 3. 마무리 안내
- "등록은 끝났어요. 검색 결과에 나오기까지 보통 며칠에서 몇 주 걸려요."라고 알려준다.
- 사이트 주소가 `https://아이디.github.io/저장소이름/` 형태라면, 검색엔진은 주소 맨 앞(`https://아이디.github.io/robots.txt`)의 robots.txt만 읽기 때문에 이 사이트의 robots.txt는 적용되지 않는다고 짧게 알려준다. 사이트맵을 직접 제출했으므로 등록에는 문제가 없다. 제대로 하려면 저장소 이름을 `아이디.github.io`로 하거나 개인 도메인을 연결하면 된다.
