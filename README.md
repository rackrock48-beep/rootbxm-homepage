# 홈페이지 템플릿

Claude에게 말로 요청해서 홈페이지를 만들고 인터넷에 올리는 템플릿입니다. 코드를 몰라도 됩니다.

## 처음 한 번만 준비하기 (Windows)
1. **Git 설치**: https://git-scm.com 에서 내려받아 설치합니다. 설정은 바꾸지 말고 "Next"만 누르면 됩니다.
2. **Claude 설치 후 로그인**: Claude Code를 설치합니다. Pro 이상 유료 플랜이 필요합니다.
3. **GitHub 가입**: https://github.com/signup

## 시작하기
1. 이 폴더를 원하는 곳에 압축 해제합니다.
2. Claude에서 이 폴더를 엽니다.
3. **"뭐부터 해야 해?"** 라고 물어보세요. 필요한 프로그램 설치, 미리보기, 인터넷에 올리기, 도메인 연결, 구글·네이버 검색 등록까지 Claude가 단계별로 안내합니다.

## 이렇게 말하면 됩니다
- "회사명을 ○○로 바꿔줘"
- "갤러리 섹션 빼고 카드 섹션을 위로 올려줘"
- "브랜드 색을 초록색으로 바꿔줘"
- "사이트에 올려줘"
- "구글이랑 네이버에 등록해줘"
